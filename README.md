# 四六级词汇每日背诵清单

> 把四六级大纲词表变成一份离线可用的单文件背诵清单。
> A dependency-free, offline single-file HTML vocabulary planner for CET-4 / CET-6.

## 这是什么

一份 Word 大纲词表 → **一个单文件 HTML 背诵清单**。双击就打开，不联网、不要服务器、没有任何运行时依赖。

- **5,271 词**（四级 4,075 + 六级 1,196），**176 天**，每天 30 词
- 音标为**英式**（OALD 记法）；释义与音标由 ECDICT 词库合成后直接内嵌进 HTML
- 学习进度存在浏览器 localStorage 里，手机和电脑各存一份，用 `⇅` 手动搬运
- 生成脚本是 Python，产物是纯静态页面；测试用 jsdom，但产物本身不依赖 Node

## 快速开始

### 用法一：直接使用（零依赖）

1. 下载或克隆本仓库。
2. 双击 `out/四六级词汇背诵清单-派生词条版.html`，浏览器打开即用。
3. 手机上把该文件发过去（微信传给自己即可），用手机浏览器打开。

不需要安装 Python、Node，也不需要起本地服务器；断网状态下功能完整。

### 用法二：修改后重新生成

只改页面样式或交互时，`out/words.json` 已经入库，直接渲染即可（仅需 Python 3 标准库）：

```bash
python build_html.py     # out/words.json -> out/四六级词汇背诵清单-派生词条版.html
python verify_data.py    # 数据体检，必须打印「体检通过」
```

要改词表、重新合成释义与音标，先准备两个数据文件（见下一节），再全量重建：

```bash
pip install python-docx wordninja eng-to-ipa cmudict

python build_data.py                  # 源 docx -> out/words.json，默认每天 30 词
python build_data.py --daysize 20     # 改成每天 20 词（176 天 -> 264 天）
python build_html.py
python verify_data.py
```

`build_data.py` 读取 `data/源文档 四六级大纲词汇 六级有星标.docx`（可用你自己的同结构文档替换）和 `data/ecdict.csv`；`build_html.py` 顶部的 `VERSION` 决定输出文件名。

可选的页面测试（只测页面，不影响产物）：

```bash
npm install
node test_page.mjs      # jsdom 真跑页面：渲染/勾选/持久化/翻页/搜索/主题/复习库/检测
node test_sync.mjs      # jsdom 双实例模拟两台设备，验证导出/导入合并
```

## 功能一览

| 位置 | 功能 | 说明 |
|---|---|---|
| 主体 | 每日清单 | 当天 30 词，四级/六级分两块；点词卡左上角圆圈记为「已掌握」 |
| 分块标题行 | 折叠分块 | 点一下收起/展开这一块，两块各折各的、每天各记各的；收起的块「当天检测」不考 |
| 顶部 `☀` | 深浅色切换 | 一键切换明暗主题，跟随系统偏好，手动选择会被记住 |
| 顶部 `⇅` | 导入 / 导出 | 把学习数据导出为剪贴板文本或 `.json` 文件，在另一台设备导入合并 |
| 顶部 `▣ 检测` | 抽题检测 | 弹层里选范围（复习库 / 全部 / 已掌握）和题数；不受折叠影响 |
| 顶部 `☑ 当天检测` | 当天一键检测 | 直接测当前翻到的那一天；跟着折叠走，折掉一块就只考另一块，题数随之变化；两块都折则按钮置灰 |
| 顶部 `★ 复习库` | 复习库管理 | 列表、单个移除、跳转定位、两段式清空，以及「决战复习」 |
| 答题页 | 英译汉申诉 | 英译汉答错时可点「我写对了」记住这串答案，下次同串直接判对，也可取消该记忆；汉译英答案唯一，不提供此入口 |
| 答题页 · 判分后 | 回看与重做 | 「上一题」回看当时的判分页；「重新答题」就地重做，以最后一次判分为准 |
| 左边缘 / 键盘 | 翻页 | 点左右箭头或按 `←` `→` 切换上一天/下一天 |
| 搜索框 | 全表搜索 | 按单词或中文释义搜索，结果按匹配程度排序（词头精确 > 前缀 > 词头包含 > 释义命中）并高亮命中处 |
| 搜索历史 | 最近查词 | 空搜索框时列出最近 20 条，带音标/词性/翻译，点一下回到那张词卡 |
| 决战复习库 | 双向出库 | 每场每个词只考一个方向（优先未过的方向），两个方向跨场累计、都通过才出库；答对即出库，中途退出也算数 |

**手机 ↔ 电脑同步**：在一台设备点 `⇅` →「复制到剪贴板」或「下载 .json」，把内容发到另一台设备，再点 `⇅` → 粘贴 →「导入并合并」。合并采用「时间更晚的操作胜出」：移出压过更早的加入，移出后重新加入则会回来；判分记忆按「词 + 那一条答案」单独计时。导入前会显示合并前后的词数供核对。

## 数据来源与再生流程

- **词表**：来自四六级大纲词汇的 Word 文档（第三方整理版，含六级星标）。该文档版权状况不明确，因此不入库。
- **释义与音标**：来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）。`ipa_uk.py` 把 ECDICT 的老式音标记法转写成现代英式 IPA，不重新推导音素。
- **`out/words.json`**：已经合成好的可用数据（原始词条 + 释义 + 音标 + 派生词 + 拼写变体表 + 按天分组），仓库内直接可用，不必先跑 `build_data.py`。

完整管线：

```
源 docx ──build_data.py──> out/words.json ──build_html.py──> out/四六级词汇背诵清单-<VERSION>.html
                                │
                          verify_data.py 校验
```

如果只改页面：改 `build_html.py` 里的 `TEMPLATE`，跑 `build_html.py` 与 `verify_data.py`。
如果要改词表：自行下载 ECDICT 的 `ecdict.csv` 放到 `data/`，准备同结构的源 docx，依次跑 `build_data.py` → `build_html.py` → `verify_data.py`。

**版本策略**：一个版本一个文件，不覆盖旧产物。`build_html.py` 顶部的 `VERSION` 是当前版名（名字取自这一版新加的功能），历史定稿放进 `out/archive/`，详见 `VERSION_LOG.md`。

## 已知限制

- **分天是构建时固化的**：176 天由 5,271 词按源文档顺序每 30 词切一段得到，不按难度或主题编排；改天数要用 `--daysize` 重建。已掌握标记与复习库按单词记录，可以延续，但「当前翻到第几天」会按新分天错位。
- **进度不自动跨设备同步**：数据只存在当前浏览器的 localStorage 里，换设备、换浏览器或清理站点数据都不会自动带过去，需要用 `⇅` 手动导出再导入。
- **只有英式音标**：源词表使用英式拼法，音标统一为 OALD 记法；习惯美式音标的使用者需要自行转换。
- **完整重建需要自备源文档**：仓库只保留合成后的 `out/words.json`，源 docx 与 65.9 MB 的 ECDICT 均未入库，因此从零重建词表需要自己准备这两份数据。
- **词表本身是第三方整理稿**：个别拼写错误已在 `build_data.py` 的 `TYPO` 表中逐条修正，但不能保证与原大纲完全一致。
